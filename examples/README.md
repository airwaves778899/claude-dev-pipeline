# Examples

This directory contains **real sample outputs** produced by running `claude-dev-pipeline` on a user authentication feature request.

## Scenario

**Input prompt:**
```
/claude-dev-pipeline:dev-pipeline start "Add user authentication with email + password login"
```

## Files

| File | Agent | Description |
|------|-------|-------------|
| [`.pipeline/pm.md`](./.pipeline/pm.md) | PM Agent | Structured PRD with user stories, acceptance criteria, and scope |
| [`.pipeline/architect.md`](./.pipeline/architect.md) | Architect Agent | 3 architecture options + selected design with API contracts and DB schema |
